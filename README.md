# الجميلة أم جميلة ♥️ — نسخة GitHub Pages للآيفون

هذا مشروع موقع PWA يثبت على شاشة الآيفون، ويحتفظ بعمر الحمل المحسوب تلقائيًا من موعد الولادة أو تاريخ آخر دورة، ويتيح اليوميات والمواعيد والقائمة والنسخ الاحتياطية.

## نشره من GitHub مثل موقع النادي

1. أنشئ مستودع GitHub جديدًا، مثل `aljameela-um-jameela`. لا تنشئ ملفات تلقائية إذا كنت سترفع المشروع من الصفر.
2. ارفع **محتويات هذا المجلد كلها** إلى جذر المستودع (مجلد `site` وكذلك `.github` و`supabase` و`README.md`). عند فك ZIP انتبه لإظهار الملفات المخفية `.github`.
3. تأكد من وجود فرع `main`. من Settings → Pages → Build and deployment اختر **GitHub Actions**.
4. اذهب إلى Actions وتابع سير عملية `نشر الجميلة أم جميلة على GitHub Pages`. بعد نجاحها سيظهر رابط `https://USERNAME.github.io/REPOSITORY/`.
5. أرسل الرابط للزوجة، تفتحه في Safari ثم مشاركة → إضافة إلى الشاشة الرئيسية. تُدخل موعد الولادة **بعد فتح الأيقونة من الشاشة الرئيسية**. حساب عمر الحمل يتحدث تلقائيًا ولا يعود إلى الصفر عند إغلاق التطبيق.

> ملاحظة: مستودعات GitHub Pages المجانية غالبًا تحتاج أن تكون عامة. لا تحفظ فيه أسرارًا أو بيانات الزوجة. الملفات العامة مجرد كود، واليوميات والتاريخ لا توجد فيه.

## إشعارات حقيقية كإشعارات موقع النادي

**GitHub Pages خدمة ملفات فقط، ولا يمكنها إرسال إشعارات من نفسها.** ملفات هذا المشروع تتضمن زر إشعارات حقيقي لكن لا يعمل قبل تهيئة خادم مستقل للإرسال. المثال الموجود هنا يستخدم **مشروع Supabase مستقل** ولا يلمس قاعدة بيانات النادي.

1. أنشئ مشروع Supabase منفصلًا، أو اطلب ربط مشروع منفصل لديك، وفعّل **Anonymous Sign-Ins** من Authentication → Providers. ليس من الضروري أن تكتب الزوجة بريدًا أو كلمة مرور؛ الهوية المجهولة تبقى على نفس الجهاز حتى حذف بياناته.
2. نفذ SQL الموجود في `supabase/schema.sql` من SQL Editor. هذا يخزن فقط تاريخ الولادة المتوقع وعنوان اشتراك الإشعارات، **لا يخزن اليوميات**. لا تنشر بياناتها خارج RLS أو في GitHub.
3. أنشئ مفاتيح VAPID عامة/خاصة عبر `npx web-push generate-vapid-keys`. احتفظ بالخاصة سرًا.
4. من Supabase → Edge Functions، انشر وظيفتي `umj-register-push` و `umj-weekly-push` من مجلد `supabase/functions`. عند نشرهما اضبط `verify_jwt=false` لكل منهما **لأنهما يتحققان من صلاحية الطلب داخليًا** (الأولى تتحقق من JWT الخاص بالمستخدم، والثانية من مفتاح cron السري). لا تُعطِ المفتاح الخاص للمتصفح.
5. اضبط Secrets في Supabase Edge Functions:
   - `UMJ_ALLOWED_ORIGIN` = `https://USERNAME.github.io` **بدون مسار المستودع**.
   - `UMJ_VAPID_SUBJECT` = `mailto:YOUR_REAL_EMAIL`.
   - `UMJ_VAPID_PUBLIC_KEY` و `UMJ_VAPID_PRIVATE_KEY` = مفاتيح VAPID.
   - `UMJ_CRON_SECRET` = قيمة سرية عشوائية طويلة (مثل 32+ بايت).
   - Supabase يوفر `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` في بيئة وظائفه. تحقّق من وجودها في مشروعك.
6. عدّل `site/push-config.js` وأضف فقط عنوان Supabase ومفتاح النشر **العام** ومفتاح VAPID **العام**. لا تضف `service_role` أو VAPID الخاص أو `UMJ_CRON_SECRET` لهذا الملف.
7. افتح `supabase/schedule.sql.example` واستبدل المرجع والسر، وشغله في SQL Editor. عند الجدولة ينبغي أن يتطابق السر في Vault مع `UMJ_CRON_SECRET`. الوظيفة تعمل كل يوم الساعة 09:00 بتوقيت الرياض، ولكن ترسل فقط عند انتقال الأسبوع، مرة واحدة لكل أسبوع لكل جهاز.
8. ادخل إلى أيقونة التطبيق المثبتة من الشاشة الرئيسية على الآيفون (iOS 16.4+)، واذهب إلى زر **تفعيل إشعارات التطبيق** ثم وافق على الإذن. لن يظهر طلب الإذن من Safari العادي على iPhone.

**قبل الإعداد**: يظهر زر الإشعارات لكنه يوضح أن الاتصال بالخدمة لم يُضبط، ولا يزعم أنه فعّال. تبقى تذكيرات تقويم الآيفون (`.ics`) متاحة كحل مؤقت.

## الحفظ والخصوصية

- حساب أسابيع الحمل يعتمد على تاريخ الميلاد المتوقع أو آخر دورة مسجّل في **localStorage** على نفس تثبيت التطبيق، ويُعاد حسابه كل يوم بتوقيت الرياض، لذلك لا ينسى أين وصل طالما لم يُمسح التخزين.
- بيانات اليوميات والأحداث محلية ولا تذهب إلى Supabase أو GitHub.
- الاشتراك في Push اختياري، وحين تفعله يُحفظ موعد الولادة المتوقع وبيانات وصول الإشعار إلى Supabase ليتم حساب وقت التنبيه.
- عند تغيير التاريخ الطبي تُحدّث بيانات الإشعارات على الخادم في المرة التالية التي يفتح فيها التطبيق أو عند إعادة التفعيل. ولضمان مزامنة دائمة بين أجهزة متعددة أو بعد حذف التطبيق يلزم تسجيل دخول/نسخ احتياطي سحابي مستقبلاً.
- لتجنب فقد التاريخ، صدّر نسخة احتياطية من الإعدادات. لا تحذف أيقونة التطبيق أو بياناته دون نسخة.
- إشعارات الويب ليست مضمونة 100% بسبب وضع التركيز، انقطاع الإنترنت، أو حالة خدمة الإرسال.

## الاختبارات

هذا المشروع ثابت بدون خطوة `npm build`. بعد رفعه إلى GitHub تنتشر ملفات مجلد `site` آليًا عبر GitHub Actions. اختبر فتح الأيقونة وتفعيل الإشعارات على آيفون فعلي بعد إكمال تهيئة Supabase.

لا تتضمن هذه الحزمة بيانات حمل حقيقية ولا أسرار خدمة.
